1. Architecture pédagogique en 3 remises Cliquer une étape

Remise 3 — Composite & Command Design Patterns

Group (Composite) + CommandManager avec deux Deque (undos / redos) et restauration à l'indice exact.

3. Carte des zones grises Cliquer une ligne pour inspecter

Chaque ambiguïté de spécification se traduit directement par des divergences d'implémentation chez les étudiants.

Sujet Ce que dit l'énoncé Ce qui casse en pratique Décision recommandée
Z-order (chevauchement)
Remise 1		 « vérifier si une forme occupe ce point » (p. 5), sans ordre. getShapeAt(Point) et getColorAt divergent selon le sens de parcours. Dernière forme ajoutée au-dessus (parcours inversé).
Dimensions & bornes
Remise 1		 Pas de contrainte sur radius, width, height ni sur les bords. Rayon <= 0 accepté ; rectangle de largeur 5 couvre 5 ou 6 cases selon < vs <=. Exiger dimensions > 0 et fixer la convention des bords.
Parsing & erreurs CLI
Remise 2		 Commandes sur 1 ligne via regex, sans format d'erreur. Une entrée invalide fait planter start() au lieu d'afficher une erreur et boucler. Préciser : commande invalide = message d'erreur sans quitter.
Couleur d'un Group
Remise 3		 Note 1 : couleur peut être celle de la 1re forme. color 0 X suivi de ungroup 0 : les enfants gardent X ou retrouvent leur couleur ? Trancher explicitement (masquage vs propagation).
Group + serial
Remise 3		 GeometricalShape est sealed (Disc, Rectangle, Square). listShapes() plante ou ignore les groupes en Remise 3. Ajouter GroupShape à serial ou documenter le mapping.
undo/redo vs indices
Remise 3		 group/ungroup en bonus ; commandes par index. Un group non-annulable décale les indices et corrompt les undo précédents. Passer Shape aux commandes Move/Color, ou group obligatoire.

6. Extraits prêts à copier-coller LaTeX / JUnit 5

Ressources prêtes à insérer dans l'énoncé et dans le dépôt de tests.

Encadré « Cas limites & invariants attendus »

Cas limites & invariants attendus :
- Dimensions : radius > 0, width > 0, height > 0 (sinon IllegalArgumentException).
- Chevauchement : en cas de superposition, la dernière forme ajoutée est affichée au-dessus.
- Groupes : group rejette les indices hors bornes ou dupliqués (ex: group 1 1).
- Undo / Redo : toute nouvelle commande exécutée via doCommand vide la pile redos ;
  undo() et redo() sur pile vide sont sans effet (pas d'exception).

Suite JUnit 5 « Scénarios croisés » (Remise 3)

@Test
void deleteThenUndoRestoresAtExactIndex() {
    AsciiPaint paint = new AsciiPaint();
    paint.addShape(new DiscShape(2, 2, 1, 'a'));
    paint.addShape(new DiscShape(5, 5, 1, 'b'));
    paint.removeShape(0);
    paint.undo();
    assertEquals('a', paint.getColorAt(2, 2));
    assertEquals(2, paint.listShapes().size());
}

@Test
void newCommandClearsRedoStack() {
    AsciiPaint paint = new AsciiPaint();
    paint.addShape(new DiscShape(2, 2, 1, 'a'));
    paint.undo();
    paint.addShape(new SquareShape(4, 4, 2, 's'));
    paint.redo(); // ne doit pas ré-ajouter 'a'
    assertEquals(' ', paint.getColorAt(2, 2));
}

@Test
void groupMoveUngroupPreservesTranslation() {
    AsciiPaint paint = new AsciiPaint();
    paint.addShape(new DiscShape(2, 2, 1, 'c'));
    paint.addShape(new SquareShape(10, 10, 2, 's'));
    paint.group(0, 1);
    paint.moveShape(0, 3, 0);
    paint.ungroup(0);
    assertEquals('c', paint.getColorAt(5, 2));
    assertEquals('s', paint.getColorAt(13, 10));
}
